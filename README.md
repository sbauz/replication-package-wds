Purpose & Reviewer Context

The primary purpose of this repository is to ensure full transparency, reproducibility, and independent verification of the Principal Component Analysis (PCA), dimensional diagnostics, and spatial statistics reported in the study.
Specifically, this package documents the rigorous corrections, diagnostic tests, and sensitivity analyses implemented to address the methodological feedback provided by Reviewer 2. It directly addresses concerns regarding:
1. PC1 Variance & Bipolar Interpretation: Diagnostic checks on variance extraction and structural meaning.
2. Dimensional Indices: Substantive diagnostics using IV-SE, IV-HAB, IV-PROD, and IV-SAL (clarified as internal diagnostics rather than independent validation).
3. Sampling Strategy: Addressing non-probability sampling constraints and representativeness.
4. Spatial Weights: Sensitivity analysis across multiple KNN neighborhood definitions (k = 6, 8, 10).
5. Methodological Citations: Proper sourcing and contextualization of the Getis-Ord and spatial methods.
6. FDR Dependence Assumptions: Testing Benjamini-Hochberg FDR assumptions and resolving discrepancies between Local Moran's I and Getis-Ord \(G_{i}^{*}\).
7. Matrix Instability: Correcting tetrachoric matrix non-positive definiteness using cor.smooth() and Higham’s (2002) nearPD adjustment.
8. PCA Assumptions & Reliability: Evaluating KMO/Bartlett criteria and addressing potential inflation in Cronbach's Alpha.
9. Resampling & Spatial Dependence: Substituting standard i.i.d. bootstrap with a Spatial Block Bootstrap to handle PC1 skewness and spatial autocorrelation.

Repository Structure


1. R Scripts (/)

The analysis follows a strict sequential pipeline. Run these scripts in chronological order:
• 01_data_preparation.R: Loads the raw programme survey data, applies exclusion criteria (418 total exclusions: 389 rice-only, 19 maize-only, 10 mixed households), and constructs the final 88 retained binary indicators.
• 02_pca_analysis.R: Computes the tetrachoric correlation matrix, implements cor.smooth() and nearPD() adjustments, runs the main PCA, executes Parallel Analysis, and performs a domain-balanced PC1 sensitivity analysis.
• 03_dimensional_indices.R: Constructs the sub-domain indices (IV-SE, IV-HAB, IV-PROD, IV-SAL) utilized as structural diagnostic tools.
• 04_spatial_analysis.R: Defines KNN weights matrices (k = 6, 8, 10), computes Global Moran's I (with 95% CI), evaluates Local Moran, Getis-Ord, and Local Geary statistics, and applies both BH-FDR and Permutation-FDR corrections.
• 05_bootstrap_sensitivity.R: Executes the Spatial Block Bootstrap by resampling at the canton level to account for spatial dependency, outputting corrected standard errors.
• 06_figures_tables.R: Reproduces all manuscript figures using the colorblind-safe Okabe-Ito palette, GADM Guayas geographical boundaries, and the UTM 17S projection. It also exports the supplementary tables.

2. Data Files (/data)

• data/anonymized_households.csv: Anonymized household-level dataset. It includes true analytical UTM coordinates for spatial computations, alongside generalized display coordinates (fuzzed to a 1-km grid) to fully protect participant confidentiality.
• data/indicator_dictionary.csv: Metadata for the 88 retained binary indicators, specifying their respective vulnerability domain, directional valence, and meaningful loading status (loading ≥ 0.30).
• data/synthetic_test_dataset.csv: A fully functional synthetic dataset that mimics the structure of the real data, allowing users to validate the code execution without accessing confidential records.

3. Supplementary Outputs (/outputs)

Pre-computed analytical tables generated by the R pipeline:
• Table_S1_exclusions.csv: Detailed categorical breakdown of the 418 excluded survey responses.
• Table_S2_crop_stratified.csv: Sensitivity analysis stratified by crop type (Rice vs. Maize) showing a Tucker Congruence Coefficient of 0.67.
• Table_S3_spatial_sensitivity.csv: Spatial metric stability across k = 6, 8, 10 and 95% confidence intervals for Global Moran's I.
• Table_S4_parallel_analysis.csv: Factor retention diagnostics comparing Parallel Analysis (retaining 28 components) against the Kaiser Criterion (retaining 32).
• Table_S5_block_bootstrap.csv: Standard errors and confidence intervals derived from the Spatial Block Bootstrap procedure.
• Table_S6_loadings.csv: Complete PCA factor loading matrix for all 88 indicators (highlighting the 41 meaningful loadings).
• Table_S7_tetrachoric_diagnostics.csv: Log of maximum absolute changes introduced during cor.smooth and nearPD matrix smoothings.
• Table_S8_missingness.csv: Item-level missing data diagnostics (ranging from 0% to 93.4%; mean missingness of 22.3%).
• Table_S9_fdr_results.csv: Comparative outputs for BH-FDR and Permutation-FDR corrections across Local Moran, Getis-Ord, and Local Geary statistics.
